Install Quarto

Follow these steps to install and start playing Quarto:

  1. Install Java 21 (JDK) and Maven.
  2. Clone the repository from GitHub.
  3. Optional: start the database with docker compose up -d in the game folder (needed for accounts and the leaderboard).
  4. Run mvn javafx:run in the game folder, or choose "Play as Guest" to play without a database.
