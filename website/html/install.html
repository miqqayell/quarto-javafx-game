Install Quarto

Follow these steps to install and start playing Quarto:

  1. Ensure you have Java 11 or later installed.
  2. Download the latest release from our GitHub repository.
  3. Unzip the folder and navigate to the project directory.
  4. Run the application using the provided executable or compile from source with JavaFX support.
  5. On GitHub, you will find information about future updates, features etc.
