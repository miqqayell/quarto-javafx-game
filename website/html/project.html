The Journey Behind Quarto

Our project is a modern, full-featured digital adaptation of Quarto, a renowned strategic board game, developed using JavaFX and integrated with a PostgreSQL database for persistent player statistics and game history.

🧠 Technical Features

This project is a digital version of the strategic board game Quarto, built with JavaFX and backed by a PostgreSQL database. Players take turns placing pieces defined by four binary attributes — size, shape, fill, and color — aiming to align four that share a common trait.

💻 Development Phase

Teammate 2 built the core JavaFX structure and backend mechanics to ensure responsive, error-free gameplay.

🎨 Visual Design

Teammate 1 crafted the visual identity, from user-friendly interfaces to the organic aesthetic you see today.

🔍 Team Collaboration

This project combined frontend, backend, and database development into a cohesive application — blending gameplay, design, and data for a complete Quarto experience.
