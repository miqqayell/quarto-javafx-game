Project History

Sprint 1

Planned and designed core systems in the first sprint. Created diagrams, database schemas, and game flow concepts. Defined game logic and user experience to lay a solid development foundation.

Sprint 2

During this sprint, the team began developing the beta version of the game and fixed issues identified in the first sprint. We improved the game logic and user interface, set up a web server to host the game, and added game statistics tracking to analyze player behavior and enhance the overall experience.

Sprint 3

In Sprint 3, the team focused on finalizing core features and preparing for the upcoming presentation. We polished the UI, ensured the player-vs-computer mode worked smoothly, and launched a project website showcasing the game, its features, and development process. Both the game and website were deployed for public access.

Sprint 4

In Sprint 4, the team focused on final steps—polishing the game, finalizing details, and uploading the website to the server for public access.

University project (KdG Applied Computer Science, 2025). Quarto is a game by Gigamic; this project is not affiliated with Gigamic.
